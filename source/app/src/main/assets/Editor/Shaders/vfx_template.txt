/* DOCUMENTATION
Shader rendering engine is Google filament, search about Google filament shader attributes and uniforms

It runs on all rendered vertices and pixels of the scene.
Using emitter.position is optional.
A VFX effect can modify the entire scene without relying on the emitter's position.

The dynamic time value is available as vfxParams.time and is not shown in the inspector.

Functions must begin with the prefix "vfx_fn_"
Structs must begin with the prefix "VFX_STRUCT_"

How to access parameters:
-Use vfxParams instead of materialParams.
-And it can only be accessed in the main function (vfx_fn_fragment or vfx_fn_vertex). If you need to access parameters in external functions, pass them as arguments.

It is possible to sample decal textures using:
float4 decal(int layer, float2 uv);
float4 decalPixel(int layer, float2 uv);

Properties inspector params:
Param types:
    rgba -> color converts to float4
    rgb -> color converts to float3 (no alpha)
    float -> float
    float2 -> vector2 converts to float2
    float3 -> vector3 converts to float3
    float4 -> vector4 converts to float4
    float01 -> shows a 0..1 slider
    bool -> shows a toggle mapped to a float in shader (1.0 == true)
    int -> integer

Precisions:
    low, medium & high

Struct DOC:
struct VFXMaterialInputs:
    float4 baseColor;
    float4 emissive;
    float4 postLightingColor;
    float  roughness;
    float  metallic;
    float  reflectance;
    float  ambientOcclusion;
    float3 normal;
    float transmission;
    float3 absorption;
    float ior;
    float microThickness;
    int model;
struct VFXEmitter:
    float3 position;
    int index;
struct SubMaterialData:
    float2 parallaxDelta;
    float3 normalDisturb;
*/
